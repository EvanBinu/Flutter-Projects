## 🔧 Getting Started

To run any project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/flutter-mini-projects.git
   cd Flutter-Projects
   ```

2. **Navigate to a project folder:**
   ```bash
   cd dice  # or any other folder
   ```

3. **Run the app:**
   ```bash
   flutter pub get
   flutter run
   ```
